# ידידים – מחשבון כבלים

אתר קטן למוקדני ידידים שעוזר להחליט מראש אילו כבלים לשלוח: **כבלים חזקים** או **כבלים רגילים** – לפי שם הרכב והשנה, או לפי מספר רישוי.

הפרויקט כולו קבצים סטטיים (HTML/CSS/JS), עובד גם בלי אינטרנט, וניתן להוספה למסך הבית בטלפון כאפליקציה.

---

## 1. איך הוא מחליט

ברגע שאחד מהתנאים הבאים מתקיים – **כבלים חזקים**:

| תנאי | איך הוא נבדק |
|---|---|
| נפח מנוע **1950 סמ״ק ומעלה** | שדה `nefah_manoa` ממאגר הדגמים |
| **טורבו-דיזל** | דיזל עם יחס כוח/נפח ≥ 48 כ״ס לליטר; אם אין נתון כוח, דיזל מ-2000 ואילך נחשב טורבו |
| **רכב מסחרי** | `sug_degem = M/N` במרשם, או מרכב שמופיע ברשימת המרכבים המסחריים |

אחרת – כבלים רגילים.

כל הכללים נמצאים בראש הקובץ [app.js](app.js) (קבועים `CC_STRONG`, `TURBO_DIESEL_HP_PER_L`, `TURBO_DIESEL_FALLBACK_YEAR`, `COMMERCIAL_TYPES`, `COMMERCIAL_BODIES`). לשנות ערך – שומרים את הקובץ ומרעננים. לפרסום מחדש של האתר, ראו למטה.

---

## 2. מקור הנתונים

- **חיפוש לפי שם** – טוען מראש את הקובץ [data/cars.json](data/cars.json), שנבנה מ"נתוני דגמים ברכב פעיל" של משרד התחבורה ב-[data.gov.il](https://data.gov.il), משאב `142afde2-6228-49f9-8a29-9b6c3a0cbe40`. כולל שם יצרן, שם דגם מסחרי (kinuy_mishari), שנת ייצור, נפח מנוע, סוג דלק, סוג מרכב וכוח סוס.
- **חיפוש לפי מספר רכב** – שאילתה חיה מול משאב "רכב פעיל" `053cea08-09bc-40ec-8f7a-156f0677aff3` וחזרה למאגר הדגמים להעשרה. זה דורש אינטרנט.

הקובץ `data/cars.json` נבנה אוטומטית. כדי לרענן אותו (למשל פעם ברבעון, כשיש רכבים חדשים בשוק):

```powershell
powershell -ExecutionPolicy Bypass -File scripts/fetch_cars.ps1
```

הסקריפט עובר על כל ~100 אלף דגמים בקטלוג, מצמצם לכ-21 אלף שורות של (יצרן, דגם, שנה, גרסאות), וכותב ל-`data/cars.json` (כ-5MB).

---

## 3. הרצה מקומית (לבדיקה בלבד)

מכיוון שהאפליקציה טוענת JSON דרך `fetch`, לא מספיק לפתוח את ה-HTML פשוט ב-Chrome מקומי. צריך שרת. בחלון PowerShell חדש בתוך תיקיית הפרויקט:

```powershell
$env:YEDIDIM_ROOT = (Get-Location).Path
powershell -NoProfile -File scripts/serve.ps1
```

ואז לפתוח בדפדפן: `http://localhost:8787/`

(אפשר גם `python -m http.server 8787` אם מותקן פייתון.)

---

## 4. פריסה ב-GitHub Pages

1. צרו ריפו ציבורי חדש ב-GitHub (למשל `yedidim-cables`).
2. העלו את כל תוכן התיקייה – `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `data/`, `icons/`, `scripts/` – לשורש הריפו (branch `main`).
3. ב-GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch** → בחרו `main` / `(root)` → Save.
4. אחרי דקה-שתיים יהיה כתובת: `https://<USERNAME>.github.io/yedidim-cables/`.

### להעלאה מהמחשב (אם זה פעם ראשונה)

להתקין את [GitHub Desktop](https://desktop.github.com/) (הכי פשוט למי שלא עבד עם git), לפתוח "Add Local Repository" ולכוון לתיקייה הזאת, ולבחור "Publish repository" → Public → Push.

---

## 5. התקנה על הטלפון (כאפליקציה במסך הבית)

1. בטלפון, פתחו את הכתובת שקיבלתם מ-GitHub Pages ב-Chrome.
2. גללו עד שהאתר נטען פעם אחת לגמרי (קחו רגע לראות שיש תוצאה אחרי חיפוש). זה שומר את המאגר במכשיר, כך שתוכלו להשתמש גם בלי אינטרנט.
3. בתפריט של Chrome (3 נקודות למעלה) → **הוספה למסך הבית** / **Add to Home screen**.
4. יופיע אייקון ידידים על מסך הבית. פתיחה ממנו פותחת את האפליקציה במסך מלא.

גם ב-iPhone זה עובד (Safari → שיתוף → "הוסף למסך הבית"), אבל חוויית ה-PWA ב-iOS מעט פחות חלקה.

## 6. החלפת האייקון ללוגו הרשמי של ידידים

הלוגו הרשמי של ידידים כבר יושב בתור קובץ המקור `icons/logo-source.png`, והאייקונים לכיסאות הבית (`icons/icon-192.png`, `icons/icon-512.png`) נבנים ממנו. להחלפה בגרסה מעודכנת:

1. החליפו את `icons/logo-source.png` בקובץ PNG חדש (מומלץ 512×512 ומעלה).
2. הריצו `powershell -ExecutionPolicy Bypass -File scripts/build_icons.ps1` כדי לייצר מחדש את שני ה-PNG במידות הנכונות.
3. אם רוצים לשנות גם את הסמל הצבעוני בפינה הימנית-עליונה של האפליקציה, עדכנו את `icons/icon.svg` (זהו ציור SVG בהשראת הלוגו, לא העתק של ה-PNG).
4. דחפו את השינוי לגיטהאב.

## 7. מה כלול בתוך הפרויקט

```
.
├── index.html            – מסך ראשי, 2 טאבים (לפי שם / לפי מספר רכב)
├── style.css             – עיצוב, כולל מצב כהה אוטומטי + ידני
├── app.js                – כל הלוגיקה: חיפוש, כללים, תצוגה
├── sw.js                 – Service Worker לשימוש אופליין
├── manifest.webmanifest  – הגדרות PWA
├── data/cars.json        – מאגר דגמים (נוצר אוטומטית)
├── icons/                – אייקונים
└── scripts/
    ├── fetch_cars.ps1    – סקריפט בניית המאגר מ-data.gov.il
    ├── build_icons.ps1   – המרת SVG ל-PNG עם Edge headless
    └── serve.ps1         – שרת פיתוח מקומי
```

## 8. הערות ומגבלות

- **רכבים חשמליים** אינם מופיעים כי אין להם סוללת 12V להתנעה בצורה הרגילה. הם מסוננים אוטומטית.
- **היברידיים ופלאג-אין** נכללים – המאגר יראה את סוג הדלק.
- **טורבו-דיזל** זוהה באמצעות יחס כוח/נפח; לכן ייתכן רכב דיזל ישן מאוד שיזוהה כ"דיזל רגיל" ולא "טורבו-דיזל". מסחרים מכל סוג נשארים "חזקים" ממילא.
- **החיפוש סלחן** – מתעלם מגרשיים, מגירוש אותיות סופיות, ומשגיאות של עד 2 אותיות. אפשר להקליד בעברית או באנגלית ("Mazda", "מאזדה", "אאוטלנדר", "outlander" – הכל יתפוס).
- **הכלי הוא עזר למוקדן**, לא תחליף לשיקול דעת. במקרה של ספק – לשלוח כבלים חזקים.
